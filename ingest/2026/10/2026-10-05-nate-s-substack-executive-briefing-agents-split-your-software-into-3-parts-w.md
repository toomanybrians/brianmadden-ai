# Executive Briefing: Agents Split Your Software Into 3 Parts. Which Should You Keep Paying For?

## Insights

- Software subscriptions bundle three distinct layers — data, interface, and workflow logic — and AI agents are pulling these apart, forcing a reassessment of what's actually worth paying for in each bundle.
- Agents improve at finding, arranging, or acting on information, which gives customers reason to abandon an application's interface while still depending on its underlying data, records, or execution/approval rules.
- Employees already using agents are implicitly making strategy decisions — which data matters, which steps can be skipped, which workflows are trusted — and leadership should treat these behaviors as a source of insight before renewal/buying decisions.
- A key strategic question for buyers: which workflows are worth building in-house (e.g., a custom candidate-search process) versus which are commodity functions worth continuing to buy (e.g., payroll).
- For sellers, "we have AI" is no longer a sufficient value proposition — vendors need to demonstrate durable reasons customers should keep paying as models and agents keep improving (examples cited: Salesforce, Crustdata).
- Switching costs are now tied to which parts of an agent workflow are portable versus locked-in; this portability determines how freely a company can adopt better models or providers as they emerge.

## Quote

> "We have AI" gets you to the beginning of that conversation. There is a lot more to figure out.
