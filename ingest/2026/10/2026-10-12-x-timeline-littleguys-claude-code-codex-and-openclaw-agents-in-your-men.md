# Littleguys – Claude Code, Codex and OpenClaw agents in your menu bar

https://t.

## Insights

- littleguys is a macOS menu bar app that provides a unified interface for monitoring and controlling multiple AI coding agents (Claude Code, Codex, Gemini CLI, Goose, OpenCode, OpenClaw, Hermes) running across different machines.
- It addresses a specific friction point in agentic coding workflows: tracking agent status and approving commands currently requires hunting through terminal tabs ("[y/N]" prompts buried in terminal tab #9"); the app surfaces these as approve/deny cards instead.
- The tool supports scheduled/recurring agent routines (morning digests, nightly dependency bumps, weekly reports) that run automatically and report results back to the user.
- It aggregates agents across multiple machines (Mac mini, homelab, laptop) by auto-discovering gateways on local network/tailnet, treating distributed agent fleets as a single managed pool.
- Built on the Agent Client Protocol (ACP), positioning itself as agent-agnostic infrastructure rather than a new agent runtime — new agent types can plug in via the ACP registry.
- Emphasizes local-first/trust design: no cloud account, no telemetry, open-source (MIT), since the app holds gateway tokens and can execute real commands on the user's machines.
