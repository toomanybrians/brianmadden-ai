# OpenAI cut GPT-6.1 Sol input cost to $0.10/M tokens — here's the trade

## Insights

- OpenAI's GPT-6.1 Sol narrows the performance gap with its flagship model (Astra) on coding, computer use, and science-task benchmarks while cutting costs substantially — e.g. matching Astra on coding tasks at roughly one-sixth the price, and coming within 2 points on computer-use tasks at one-seventh the cost.
- Cached input pricing for Sol dropped to $0.10 per million tokens, a 50% reduction from the prior version and a 95% discount off standard input pricing, specifically aimed at making large-scale app deployment cheaper.
- OpenAI also launched a "Decisions API" that replaces manual if-else routing logic with a model-driven classifier (built on a tuned GPT-6 Luna) that picks from a defined set of answers in 150ms, versus 1.6 seconds for a standard Luna call — intended for use cases like support-ticket routing, content moderation, and agent action selection.
- A separate open-source tool (PageIndex) is claimed to outperform vector-based RAG by building a document tree structure instead of chunking/embedding, reportedly hitting 98.7% accuracy on a financial-document benchmark without needing a vector database.
- Other noted developments: Anthropic's Claude Sonnet 5.5 reportedly matches Opus 5.5 on agentic tasks but consumes 7x more tokens; Meta has a training technique that doubles math accuracy on Qwen3-8B while shortening output length.
- Overall framing from the newsletter: the competitive frontier in AI is shifting from raw capability toward cost-efficiency — making near-top-tier performance affordable enough to deploy at scale.
