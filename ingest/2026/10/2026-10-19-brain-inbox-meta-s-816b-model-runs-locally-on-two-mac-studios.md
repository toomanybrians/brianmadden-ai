# 🧠 Meta's 816B Model Runs Locally on Two Mac Studios

## Insights

- Meta released "Muse Spark Open," an 816B-parameter open-weight model using a mixture-of-experts design where only 42B parameters activate per request (likened to 8 of 256 specialists running at once), aimed at coding and long agentic tasks.
- The model supports a 1M-token context window, multimodal input (text, image, video, audio), and can run locally on two Apple M5 Ultra Mac Studios via the MLX framework, without cloud infrastructure — also available via API (Groq, Together AI, OpenRouter) or Hugging Face weights, with PyTorch fine-tuning support.
- Mistral released Large 4, a 1-trillion-parameter model positioned for agentic coding workflows, scoring 61.7% on DeepSWE v1.1 and leading other open models on the Coding Agent Index; API pricing cut 50%.
- A Mercor-run study pitted 12 CPAs against AI models on real accounting tasks: human accountants averaged ~37% accuracy, Gemini 2.5 Pro scored below that, Opus 5 reportedly hit 100%, and open-weight Qwen3.5-122B trailed behind.
- GPT-6 reportedly solved 49 of 50 expert-level physics problems at 98% accuracy, at a cost of about $3 per problem.
- OpenAI shipped GPT-Live-1.1, a voice model update with 13 new voices across six languages, more natural accents/handoffs, and improved steerability, rolling out to all ChatGPT/Codex/Dots users (API access pending).
