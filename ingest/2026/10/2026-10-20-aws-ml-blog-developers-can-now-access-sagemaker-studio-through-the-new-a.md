# Developers can now access SageMaker Studio through the new AWS experience

## Insights

- AWS has removed the traditional account-creation friction for new SageMaker AI customers: sign-up now uses existing identities (Google, GitHub, Apple, Amazon, or email) instead of requiring phone verification, credit card, or support plan selection, cutting sign-up to 2–3 steps.
- New customers land directly in a pre-configured SageMaker Studio environment (creation time previously reduced from 2 minutes to ~20 seconds) rather than a blank AWS console, with permissions for training, evaluation, and deployment already set up — no manual IAM role configuration needed.
- Free Tier incentive: $100 in credits automatically applied across SageMaker AI services (training, customization, notebooks, endpoints), with a chance to earn another $100; usage auto-stops after 6 months or credit exhaustion, with no surprise billing.
- This builds on a prior integration with Hugging Face ("deep links" from model pages into SageMaker Studio workflows), so a developer can go from browsing a Hugging Face model to a pre-configured deployment page within the new onboarding flow.
- Eligible new accounts get default access to GPU instance types (G5, G6, G4dn) for training/endpoints/notebooks, and the Studio instance-selection UI now surfaces real-time quota availability.
- Framing throughout targets individual developers and small startup teams specifically, positioning this as lowering the barrier to experimentation/prototyping rather than enterprise-scale adoption.

## Quote

> The new sign-in experience removes the last major hurdle between discovering and building with Amazon SageMaker AI.
