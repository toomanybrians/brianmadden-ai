# Amazon Polly delivers a major upgrade to its Generative engine

## Insights

- AWS upgraded Polly's Generative engine as a drop-in replacement for existing generative voices — same voice names, same API calls, no code changes, no price increase, positioned explicitly to avoid migration friction for enterprise customers.
- Catalog now totals 57 generative voices across 11 languages and 25 locales, with 14 new voices added across 9 locales, including first-time generative-engine availability for Hindi and Finnish.
- Claimed improvements center on accurate entity pronunciation (numbers, currency, addresses, confirmation codes) and automatic emotional/prosodic variation based on text context, without manual SSML-style configuration — framed as reducing escalation from self-service IVR to human agents.
- Streaming is supported via a Bi-Di Streaming API (StartSpeechSynthesisStream), aimed at real-time use cases like voice agents and game characters, alongside standard SynthesizeSpeech API access.
- Named target use cases: contact centers, cascaded LLM-based voice agents, media/localization/dubbing, e-learning narration, accessibility, and interactive/transactional voice interfaces (kiosks, IVR, IoT).
- A customer reference (Sanoma Media Finland) reports publishing 10,000+ articles/month via Polly and describes the new Finnish voice as a "clear improvement" over the prior neural voice — the only independent validation point in the piece, from a vendor-selected customer quote.

## Quote

> "No cost increase, no new SKU, and no changes to your existing integration." — Amazon Polly Generative engine launch post
