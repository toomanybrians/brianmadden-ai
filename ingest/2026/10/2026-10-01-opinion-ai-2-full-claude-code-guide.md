# Full Claude Code Guide

## Insights

- Claude Code's core value isn't coding specifically — it's giving an AI model a persistent working environment (a folder/project) where it can read existing files, understand context, make changes, run tools, verify results, and retain memory across a session, rather than operating in a stateless chat window.
- Anthropic shipped two model updates in short succession: Opus 5.5 (Sept 22) for harder, open-ended tasks requiring judgment, and Sonnet 5.5 (Sept 28), which is claimed to be over 30% faster and up to 30% cheaper per task than Sonnet 5.
- Pairing these newer models with Claude Code shifts the interaction model from "ask AI how to do something" to "hand AI the actual work" — applied to files, research, apps, Obsidian vaults, scripts, GitHub projects, documents, and recurring workflows.
- The guide previews a full setup path: model selection, memory, Plan Mode, context management, Skills, subagents, MCP (Model Context Protocol), review steps, Hooks, and ultimately automations that run unattended.
