# Here’s me being wrong about how fast this would happen: https://t.co/nKhlrPeTiV

## Insights

- Miessler argues the core bottleneck in current AI use isn't model capability but the failure to articulate precise, testable definitions of what a user actually wants — vague requests produce vague/wrong outputs.
- He proposes "Ideal State Criteria" (ISC): discrete, 8-12 word, binary/testable statements describing what "done" looks like, generated by reverse-engineering a request's explicit asks, implied wants, and anti-criteria (what's NOT wanted).
- The same ISC used to define success also serve as verification criteria, enabling a "hill-climbing" loop: current state → ideal state (outer loop), and idea → test → iterate (inner loop, akin to scientific method/OODA).
- The system ("The Algorithm," built into his PAI/Claude Code setup) assigns an effort level (Instant to Comprehensive, up to 120+ min) that scales how many criteria are generated (4 to 150+) and which of ~25 capabilities (agents, debate, red-teaming, parallel execution, etc.) get engaged.
- He claims this approach generalizes beyond coding to any domain — website design, game design, pipeline architecture, even personal goals like weight loss — using the same reverse-engineer/verify/iterate process regardless of domain-specific criteria.
- He predicts labs and agentic frameworks will adopt similar "ideal state articulation + verification" mechanisms within the next few months of 2026, calling it fertile ground for AGI progress.
