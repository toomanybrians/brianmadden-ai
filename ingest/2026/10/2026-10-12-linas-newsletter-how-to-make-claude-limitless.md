# How to Make Claude Limitless ♾️

## Insights

- SemiAnalysis's October 5 study found Claude Max ($200/month) delivers roughly $11,700 of Opus 5.5 value at API prices, versus ~$2,100 of GPT-6.1 Sol value for the same spend on OpenAI's equivalent plan.
- At the $20 tier, Claude Pro allots about 2.9 billion Opus tokens monthly compared to roughly 1 billion for ChatGPT's $20 plan.
- Anthropic's subscription economics assume low utilization: gross margin on a heavy Max user is modeled at +6% at 20% usage of allowance but -369% if the user consumes the full allowance, with break-even around one-fifth of the plan.
- Most subscribers reportedly use Claude as a one-off query tool (ask, read, close tab), which is exactly the usage pattern the pricing model depends on.
- In the three weeks before publication, Anthropic shipped changes enabling heavier usage: Cowork merged into Claude chat (Sept 16) for autonomous cloud task execution, new Opus/Sonnet/Haiku 5.5 models (Sept 22–Oct 7), and monthly API credits bundled into Max/Team plans (Oct 7: $100 on Max 5x, $200 on Max 20x, up to $500 pooled on Team).
- The piece frames capturing this extra value as a matter of workflow design — scheduled, standards-loaded, self-checking agent work running in the background — rather than better prompting.

## Quote

> A $200 Claude Max plan buys about $11,700 of Claude Opus 5.5 work a month at API prices.
