# OpenAI Dots Setup and Uses (Full Guide)

## Insights

- OpenAI's "Dots" is framed as a shift from query-based AI use (asking for answers) to delegation-based use (assigning an ongoing responsibility that persists without the user present).
- Each Dot runs on "GPT-6 Astra" and is given its own dedicated cloud computer and browser, letting it operate independently of the user's device being on.
- Dots can connect to 4,000+ apps via plugins, integrate with ChatGPT Work and Codex, and use background agents to monitor changes, prepare work, and escalate only when a human decision is needed.
- Example use cases given: a creator monitoring interview transcripts for content prep, a founder maintaining launch status, a developer triaging bugs into Codex, and a consultant auto-preparing recurring client reports.
- Setup guidance emphasizes starting narrow — assign a Dot one single ongoing job rather than an open-ended "help with everything" mandate.

## Quote

> We have spent the last few years learning how to get better answers from AI. Dots is about something else: giving AI something to keep responsible for.
