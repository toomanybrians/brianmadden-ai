# 🚨 The Night Hacking Hit Machine Speed

## Insights

- AI has compressed the vulnerability-discovery-to-exploitation cycle to hours: Wiz researchers used Gemini 4 Argon and GPT-5.6 Sol to find two decade-old PHP flaws (PHP2Shell) in about a week, work that previously took a team months — but a two-month "Defender's Window" let patches and firewall rules go live before public disclosure.
- The same AI capability is weaponized on offense: Microsoft reports a China-aligned group (Storm-0940) used an open-source agent framework (ARTEX) to run an autonomous password-spray and hijacking campaign against 2,250+ cloud tenants, including over 151,000 sign-in attempts in days and privileged access gained in under three hours at some targets.
- Security is becoming an AI-vs-AI race: both attackers and defenders now deploy agentic systems at machine speed, shifting the decisive factor to who has better models finding bugs first and how fast patching pipelines can move.
- Anthropic's Claude Duet signals a shift from reactive chat assistants to proactive, always-on agents — monitoring connected apps, sending daily briefings, executing tasks (scheduling, financial forecasts, payments) via 6,000+ connectors, while still asking before sensitive actions.
- OpenAI and Google Cloud are becoming commercial partners despite being frontier-model rivals: OpenAI's models and Codex agent will be sold through Google's Model Garden/Marketplace, while Microsoft remains OpenAI's "primary cloud partner" — pointing to a less exclusive, more multi-cloud AI distribution model.
- A mathematician (Sun Zhiwei) is using AI as a research collaborator at scale, publishing 1,000 open conjectures and deliberately restricting the AI's internet access so it can't discover a problem is already known to be unsolved and refuse to attempt it.
