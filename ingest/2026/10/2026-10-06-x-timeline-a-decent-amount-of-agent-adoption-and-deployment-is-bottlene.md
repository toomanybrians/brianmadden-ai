# A decent amount of agent adoption and deployment is bottlenecked by being able t

## Insights

- Agent adoption/deployment is bottlenecked by the inability to test, tune, and optimize agents in "real" work environments — the actual files, CRM systems, email, and tools agents need to operate on.
- Testing agents directly on a real company's live data is considered unsafe, creating a gap between agent capability and deployable, validated performance.
- One proposed solution (Era, described as free and live) generates a fully simulated enterprise environment that mimics real company behavior across common enterprise tools (Salesforce, Slack, Jira, Zendesk, Gong, Deel), allowing agents to be tested without touching real data.
- The underlying claim is that you can't know how an agent is actually performing without a realistic-but-safe environment to evaluate it in.

## Quote

> You can't safely test an enterprise agent on a real company's data. So we built a company for it to work in.
