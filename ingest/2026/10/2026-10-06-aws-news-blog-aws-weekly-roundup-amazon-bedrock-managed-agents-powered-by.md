# AWS Weekly Roundup: Amazon Bedrock Managed Agents powered by OpenAI, Q3 service availability updates, Kiro workflows, and more (October 5, 2026)

## Insights

- AWS launched a public preview of Amazon Bedrock Managed Agents powered by OpenAI — a customized, AWS-native version of OpenAI's Agents API, letting agents run entirely inside AWS using existing identities, permissions, and governance, with a choice of self-hosted compute or managed Bedrock AgentCore Runtime.
- New frontier models added to Bedrock include OpenAI GPT-6.1 Sol (claimed near-GPT-6 Astra performance at ~1/5 the cost), a GPT-6 Astra "UltraFast" tier (up to 6x faster inference, 300 tokens/sec), Claude Sonnet 5.5 (positioned for agentic coding workflows), and Grok 4.7 (improved repo-scale coding and browser-use agents for forms/portals).
- AWS Well-Architected Agent (preview) is an AI agent that analyzes a customer's AWS environment against business goals to produce contextual recommendations on cost, security, performance, and resilience — applying agentic AI to AWS's own architecture-review practice.
- Kiro workflows let multiple agents carry out complex, multi-step tasks with reduced human supervision; AWS states it is using this internally to build Kiro itself.
- Strands Decider is described as part of an emerging category of small "decision models" (or "system one" models), referencing TypeSafe AI's "Jev" as a precedent; Decider 2B is positioned as an open-source, lightweight model for fast local experimentation.
- AWS is formalizing a $1B Forward Deployed Engineering (FDE) organization and extending it to partners via new "Partner-Led FDE" credential pathways focused on delivering production agentic AI — a structural/organizational bet on hands-on agentic AI delivery services.
- Routine service lifecycle churn included several products moving to maintenance or sunset status (e.g., Chime SDK SIP Media App, WorkSpaces Secure Browser, Managed Blockchain, DevOps Guru, Mechanical Turk reaching end of support) — notable as Mechanical Turk's wind-down tracks the shift away from human-in-the-loop crowdwork toward agentic AI tooling.
