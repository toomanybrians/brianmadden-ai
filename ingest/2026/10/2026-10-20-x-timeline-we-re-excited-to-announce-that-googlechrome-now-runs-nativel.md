# We're excited to announce that @GoogleChrome now runs natively on Citrix #Unicon

## Insights

- Citrix now ships Google Chrome to run natively on UniconOS (formerly eLux), its immutable, lightweight endpoint OS, rather than requiring VDI to deliver a managed browser experience.
- The pitch centers on decoupling browser security from the underlying endpoint: as IT shifts users off Windows to lighter OSes to cut costs, Citrix argues security policy usually has to be rebuilt per-platform, leaving gaps — this integration is meant to close that gap.
- With Citrix SecurAccess with Chrome Enterprise, the browser itself becomes a managed security surface: zero trust network access, "AI security controls," context-aware access, real-time DLP, download/clipboard protection, dynamic watermarking, and SSO are all layered directly into Chrome.
- Framing explicitly names the browser as the primary surface for modern work — SaaS, internal apps, and "increasingly AI tools" are all accessed through it — making browser-level security a proxy for AI/data governance.
- The announcement positions this as unifying previously separate buys (secure endpoint, browser security, app delivery) into one Citrix platform (UniconOS + Chrome + SecurAccess + DaaS), explicitly pitched as ending the choice between modern browser-based work and traditional virtual app delivery.

## Quote

> "Bringing the power of Chrome to Citrix and UniconOS deployments, organizations give their employees the browser they know." — Hakan Kilic, Chrome Enterprise
