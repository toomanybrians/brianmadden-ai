## Insights

- Argues against treating code as the primary source of truth in AI-assisted development, proposing instead a three-tier hierarchy of fidelity to original intent.
- Positions human intent (what's in someone's mind) as the true, highest-order source of truth in a build process.
- Places natural-language articulation of that intent (English) as the second-order representation, more faithful than code.
- Demotes code itself to third place — an implementation artifact, further removed from original thought than either intent or its written expression.
- Suggests writing is inherently "closer" to thought than code is, implying natural-language specs/prompts carry more fidelity to intent than the resulting codebase.
