# Anthropic Dashboards 📊, OpenAI Decisions API ⚡, Claude Pen Testing 🔐

## Insights

- Anthropic has expanded Claude from chatbot into a broader workspace suite: Dashboards (natural-language querying of BigQuery/Snowflake/Salesforce/Redshift/Databricks into live, auto-updating charts, no SQL needed) and Motion (code-based, editable animations exportable as MP4), alongside Docs, Slides, and Design now out of beta and free on all tiers, including Free.
- Anthropic reports over 45 million docs/decks already created in Claude, signaling real uptake of the workspace features beyond chat.
- OpenAI's new Decisions API skips full text generation and returns typed outputs (probability, categorical choice, or ordered score) directly, claimed up to 10x faster than its standard Responses API, priced at $0.10 per million input tokens with free output tokens, and supports HIPAA/Zero Data Retention for sensitive use cases.
- Anthropic launched a tiered Cyber Verification Program giving vetted security professionals reduced safety restrictions on Claude for defense, authorized red-teaming, and (top tier) critical-infrastructure work co-vetted with the US government; in testing, Claude Opus 5.5 completed 34 of 50 offensive security tasks without being blocked.
- Partner org Glasswing reportedly used this access to find over 129,000 verified vulnerabilities, including 33,000+ rated critical or high severity.
- A separate item notes OpenAI's Navier-Stokes proof has a verification flaw: the Lean formal-proof check reportedly validates a different claim than the one made in the English-language argument, raising questions about trusting AI-assisted formal verification.
