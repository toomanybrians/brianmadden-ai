# I disagree with @mattpocockuk that the code should be the source of truth when b

## Insights

- Argues against the view (attributed to @mattpocockuk) that code is the source of truth when building software with AI assistance.
- Proposes a three-tier hierarchy of truth in AI-assisted building: (1) intent/thought in the mind, (2) natural-language articulation of that intent, (3) code as implementation.
- Frames code as a downstream artifact — a translation of language, which is itself a translation of thought — rather than the primary or most authoritative representation.
- Claims written language is a closer, more faithful representation of human intent than code.
