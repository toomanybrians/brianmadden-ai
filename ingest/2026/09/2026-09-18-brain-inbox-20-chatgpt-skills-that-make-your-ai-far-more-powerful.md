# 20 ChatGPT Skills That Make Your AI Far More Powerful

## Insights

- ChatGPT's new "Skills" feature lets users save a reusable method (instructions, examples, reference files, even scripts) instead of re-typing the same detailed prompt for recurring tasks each time.
- The core distinction drawn: a prompt specifies what you want right now, while a Skill specifies how a given type of work should be done every time.
- Skills can be invoked manually or triggered automatically when a user's request matches the task the Skill was built for.
- The feature is framed as addressing a common workflow inefficiency: repeatedly re-teaching the AI the same standards (writing style, research method, formatting preferences, fact-checking rules) across sessions.
- Skills are described as compatible with newer models (GPT-5.6 Sol and GPT-6 Astra), with Astra positioned for longer, more complex jobs spanning research, code, browsers, and software.
- Example given: a Skill for meeting transcripts that extracts decisions, action items, owners, and deadlines, with a rule against inventing missing information, then drafts a follow-up email automatically.

## Quote

> Prompt = what I want now. Skill = how I want this kind of work done every time.
