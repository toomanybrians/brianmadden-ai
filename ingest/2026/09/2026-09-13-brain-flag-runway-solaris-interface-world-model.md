# Runway introduces Solaris, an "Interface World Model"

## Insights

- Runway announced Solaris on August 31, 2026: the first of what it calls an "Interface World Model" — real-time software whose UI is generated frame-by-frame as the user interacts, rather than compiled from HTML/CSS/JS.
- Built on Runway's Gen-4.5 video model. A language model decides what should happen; a world model renders how it looks — the visible frame and its response to input are synthesized directly, with no intermediate code representation.
- Targets real-time interaction at 720p. Rendering and interaction are handled jointly by one model, which Runway frames as removing the usual design tradeoffs of a fixed, pre-built interface.
- In Runway's own user study, participants preferred Solaris-generated interfaces over a coded UI built by Claude Opus 5: 61% to 24% on following instructions, 71% to 21% on "behaving naturally."
- Status is a research preview, not a shipping product — no pricing, no public API, access is request-only.
- Runway names open problems itself: keeping generated text legible and stable, maintaining coherence over long sessions, and integrating generated interfaces with existing software infrastructure.
