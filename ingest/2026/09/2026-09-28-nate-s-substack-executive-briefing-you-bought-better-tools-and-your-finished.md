# Executive Briefing: You Bought Better Tools and Your Finished Work Still Waits

## Insights

- When one team member's output multiplies via agentic AI use, the organization's default response — asking them to teach others, document workflows, run workshops — consumes the very capacity that made them valuable, effectively giving high performers a second job.
- Individual productivity gains and team productivity gains are not the same thing: one person producing 10x the work can create a bottleneck if five others must now review/sort it, meaning the "gain" just relocates the constraint rather than removing it.
- Cited data points: Lauren Tan reportedly merged ~1,000 PRs in July and 2,462 in August; Cursor's Spring 2026 developer-habits report found the 99th-percentile user merged ~15x as many PRs as the median active PR author — though the piece cautions this doesn't prove 15x customer value or that AI caused the full gap.
- Proposes six management principles for scaling agent-driven work: make agent work usable by more than one person, separate durable work from its running environment, keep humans accountable, leave work in a resumable state, give agents a way to check reality, and remove processes whose purpose has changed.
- Warns that applying all six principles indiscriminately risks creating new bureaucracy; the real management task is judging how much of each a given team actually needs.
- Frames the core arithmetic problem: a tenfold gain in implementation speed can shrink to something like a 1.8x gain for the business overall, because other pipeline stages (review, decision-making, deployment) become the new bottleneck.
- Distinguishes standards worth imposing (e.g., requiring a reproducible test) from ones that aren't (e.g., forcing everyone to use identical prompts) — the latter can actively degrade top performers' output.

## Quote

> Everybody has better tools, and finished work still waits.
