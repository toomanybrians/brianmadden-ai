# Why the Same AI Scored 63% and 99% on the Same Test

## Insights

- ARC Prize Foundation reported two verified scores for OpenAI's GPT-6 Astra on the same ARC-AGI-3 test: 62.7% under its standard test harness versus 98.6% using an adapter built on OpenAI's own API — the model was identical, only the surrounding software/harness differed.
- OpenAI's launch materials led with the higher, adapter-based number, describing the model as "saturating" ARC-AGI-3 (99.9%), FrontierMath Tier 4 (97.6%), and ExploitBench (100%), and OpenAI president Greg Brockman said conditions now feel like "the AGI era."
- The piece argues that "saturation" (near-100% scores) means a benchmark can still distinguish weaker from stronger models below the ceiling, but can no longer register further progress once a model hits the ceiling.
- Central claim: when the vendor selling the model also controls the test harness, time limits, comparison columns, and footnotes, a benchmark result reflects the conditions imposed as much as the model's actual capability.
- Independent tracking (Artificial Analysis) reportedly placed Astra fourth of six models in a September 3 comparison and second in a revised index the next day, at 2.5x the list price of the prior model ("Sol") — illustrating a gap between vendor-reported dominance and independent third-party rankings.
- Access to Astra at launch was limited to specific tiers (ChatGPT Plus/Pro/Business/Enterprise, API rollout following days), with a separate "Daybreak" program for cybersecurity-related expanded access.
