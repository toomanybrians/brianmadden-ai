# The boring plumbing that could make AI agents actually work

## Insights

- AI development shifted from focusing purely on model capability (writing, coding, reasoning) to building connective "plumbing" — infrastructure that lets AI systems access tools, data, and other agents.
- Anthropic's Model Context Protocol (MCP), introduced November 2024, is an open standard letting AI applications connect to external tools and data sources (e.g., Google Drive, Slack, GitHub, databases) without custom one-off integrations for each.
- Google's Agent2Agent (A2A) protocol, launched April 2025, enables agents built by different companies/vendors to discover each other, communicate, and hand off tasks — e.g., a procurement agent negotiating with a supplier's agent.
- Solo.io built "agentgateway," a traffic-management control layer for the growing volume of agent-to-agent and agent-to-tool communication, addressing infrastructure needs as protocol adoption scales.
- These protocols (MCP, A2A, agentgateway, others) are converging under the Agentic AI Foundation (AAIF), a Linux Foundation initiative meant to be a neutral home for open agent infrastructure — explicitly modeled on how TCP/IP and HTTP standardized the internet.
- Industry figures argue standardization is needed across multiple layers — discovery, trust, observability, security — not just basic agent-to-agent communication, so developers don't have to keep re-solving the same integration problems.

## Quote

> A2A and MCP are bricks towards a much larger work of protocols that really all need to come together. — Mazin Gilbert, AAIF
