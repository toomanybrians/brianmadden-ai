# How to Build a $20K/Month Agentic Harness using GPT-6 Astra (Full course)

## Insights

- The article cites an ARC Prize test where the same GPT-6 Astra model scored 62.7% in one configuration and 99.9% in another (at lower cost), attributing the gap entirely to the surrounding system rather than the model itself.
- It frames "agentic harness" as the wrapper of tools, memory, retries, and workflow logic built around a model so it can complete open-ended, multi-step jobs (e.g., a weekly research/reporting task) without step-by-step prompting.
- Astra is described as already capable of browsing, file search, code writing/execution, tool use, MCP, Skills, and sustained multi-step task execution — the harness's job is to connect these capabilities into a working process.
- The business pitch: monetization comes from packaging a harness around a specific business job (research, reporting, repetitive ops work) and selling it as a subscription system, not from selling access to the underlying model.
- Illustrative math: four clients at $5,000/month = $20,000/month, positioned as a realistic small-business model built on automating a defined job function.

## Quote

> The money is in the job you automate, not the model name.
