# Fable 5.1 is quietly 45% cheaper to run #AI #Fable5 #Anthropic #APIbuilders #tokens

## Insights

- Fable 5.1's list API pricing is unchanged from Fable 5: $10/million input tokens, $50/million output tokens.
- The actual cost reduction comes from cache read pricing, which dropped from $1 to $0.25 per million tokens — a 4x cut.
- Cache reads cover repeated/reused context, which the source frames as the dominant cost driver for high-volume, real-world usage.
- Anthropic estimates typical workloads run about 25% cheaper on Fable 5.1 versus Fable 5, with highly agentic workloads (heavy cache reliance) reaching roughly 45% cheaper.
- The efficiency gain is described as easy to miss because the sticker price didn't change — the savings only show up for workloads that reuse context.

## Quote

> The savings are hiding in the cache, which is exactly where most people never look.
