# Claude Code usage limits are changing: 17% drop incoming, but still net positive

## Insights

- Anthropic is ending a temporary 50% boost to Claude Code weekly usage limits and settling at a permanent 25% increase over the original baseline — users will feel this as a 17% reduction from current (boosted) limits, even though it's still a net increase over the pre-boost baseline. Change applies across Pro, Max, Team, and seat-based Enterprise plans, effective September 14.
- Anthropic has stated it is developing better usage-visibility and control tools so users aren't caught off guard by limit changes — implying current visibility into consumption is inadequate.
- Grok Bot can now autonomously shop and pay online via a Stripe Link plugin: it searches, compares, builds a cart, and checks out, using single-use virtual cards (no exposure of real card numbers) and requiring user approval before each spend; currently US-only.
- This is framed as agents crossing a threshold "from thinking to spending" — AI agents taking on real financial transaction authority, not just information/task work, raising the question of who absorbs the real-world costs of agentic infrastructure.
- Pangram Labs released an AI text detector claiming a 99.99% true negative rate, positioned as increasingly important infrastructure as more written content is agent-generated and distinguishing human vs. AI authorship becomes harder.
- Claude Code's desktop app now supports resuming CLI (terminal) sessions mid-conversation with full context/history intact, enabling users to move fluidly between terminal and desktop environments during a coding task.
