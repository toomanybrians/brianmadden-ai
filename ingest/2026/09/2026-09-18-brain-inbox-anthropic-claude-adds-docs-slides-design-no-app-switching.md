# 🛠️ Anthropic Claude adds Docs, Slides & Design — no app-switching

## Insights

- Anthropic merged its Claude chat interface with its "Cowork" background-agent mode into a single unified workflow: tasks can be started, the laptop closed, and Claude continues working autonomously, surfacing questions to the user only when it hits a blocker.
- Three new native tools (Docs, Slides, Design) launched in beta on paid plans, letting users write/edit documents, build and present decks, and mock up visuals — all inside one conversation, without switching apps or copy-pasting between tools.
- The stated goal is an end-to-end workflow: going from a one-page doc to a full deck to matching visuals within a single chat session.
- Existing Cowork users retain their chats, projects, and files after the merge; rollout to Pro and Max plans is still pending (currently on paid plans generally, per the item).
- The newsletter frames this alongside OpenAI's release of a public bug-tracking framework for model misbehavior, characterizing both as competing bets on "trust" — one via owning the workflow, one via transparency about failure modes.
