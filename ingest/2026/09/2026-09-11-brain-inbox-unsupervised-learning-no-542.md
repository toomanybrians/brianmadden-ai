# Unsupervised Learning NO. 542

## Insights

- One writeup argues AI adoption bottlenecks aren't capability but discoverability — users don't know what a system can do, and blank-prompt interfaces fail to reveal relevant possibilities; the fix is interfaces that observe work and surface options.
- A cited essay argues AI-assisted competition is turning intellectual/creative work into a "dark forest": unfinished ideas must be hidden because others can rapidly reproduce or overtake them once shared, threatening open collaboration norms (raised via disputes over AI-assisted math proofs).
- AI coding tools are lowering the resource threshold for cyberattacks — a small outfit reportedly built a credential-harvesting campaign in under six hours using an AI chatbot, raising the concern that tiny teams can now operate with the reach of large organizations.
- A research model treats LLM adoption like a contagion moving through culture/cognition — users progress from independent thinking to coupled use to persistent dependence via social reinforcement, with small usage increases potentially triggering runaway adoption.
- One engineer's review process found AI-generated tests created false confidence, missing real bugs in an estimated 30% of pull requests due to tautologies, weak assertions, and missing edge cases — prompting use of a dedicated adversarial review step.
- A separate essay frames "writing things down" as increasingly functional infrastructure for AI collaboration: markdown files act as reusable memory that let frozen models resume work, with humans still setting goals and direction.
