# Seven sheets and 13 slides from the cheapest setting: the two-step guide and the exact prompts I use for Excel, Po…

## Insights

- Author tested "Fable 5.1" on its cheapest ("Low") effort setting against a finance task (M&A research, DCF model in Excel, PowerPoint deck), producing a working 7-sheet workbook and 13-slide deck from one short prompt.
- Proposed workflow: start every task on Low effort, review the output, then escalate to higher (more expensive) effort settings only for the specific parts requiring judgment — because a cheap-but-usable draft lets you diagnose problems before spending expensive compute.
- Argues this pattern matters more for knowledge work than code: code has built-in feedback (runs/errors/tests), but spreadsheets and decks don't signal when an assumption or argument is wrong — a spreadsheet "will calculate a bad assumption perfectly."
- Claims the value of building the artifact isn't just the output — the process of building the spreadsheet, deck, or draft is what clarifies the author's own understanding of the business/story/argument ("you discover the story as you go").
- Notes a specific gap in the Low-effort output: it omitted a Sources sheet and a Checks sheet, requiring manual work to trace assumptions — this is where a higher-effort run ("Extra") added value.
- Piece is framed as a practical companion to prompts/techniques (Excel, PowerPoint, Word prompts, writing-voice testing, instructions for long autonomous jobs) but those specifics are gated behind a paywall.

## Quote

> Building the spreadsheet changes what I understand about the business, building the deck changes what I think the story is.
