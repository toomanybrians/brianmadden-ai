# Is a person or an AI agent driving the browser? 🤔

Join our next Deep Dive webin

## Insights

- Frames a new enterprise security problem: distinguishing whether a human or an AI agent is driving a browser session, as agents increasingly browse sites, access apps, and invoke tools on a user's behalf.
- Describes a product approach (Citrix SecurAccess + Chrome Enterprise) for detecting autonomous browser activity and applying policy responses — monitor, notify the user, record the session, or block it.
- Introduces "Session Insights" as a mechanism for reviewing what a detected autonomous browser did, with AI used to flag risky moments for faster investigation and auditability.
- Highlights MCP (Model Context Protocol) tool filtering as a control method, so an agent is scoped to only the tools/actions a specific task needs rather than everything the underlying user could access.
- Positions this as an IT/security governance challenge: determining which agents can access sensitive resources and how to extend enterprise policy to autonomous, non-human activity.
