# Microsoft Ignite 2026: What’s new in Azure, the platform purpose-built for AI

## Insights

- Microsoft frames "IQ" (enterprise context — business data, logic, processes, institutional knowledge) as the new competitive differentiator now that frontier models are commoditized and equally available to all; the product response is Microsoft IQ, an "enterprise context management platform" combining Work IQ, Fabric IQ, Foundry IQ, Web IQ, and 350+ connectors so context is captured once and reused across every agent, claiming ~60,000 customers already.
- Microsoft IQ's "business plugins" let domain experts encode reusable logic (e.g., resolving a supply chain disruption by querying semantic models, supplier contracts, and ownership data) once, inherited by all agents — intended to avoid every new agent "starting from zero."
- Microsoft positions context/governance as portable across competing ecosystems: Microsoft IQ's business plugins work not just in Copilot/Foundry but in GitHub Copilot and rival assistants (Claude, ChatGPT) via MCP and APIs, with permissions/governance carried along.
- New agent-governance infrastructure introduced: Microsoft Entra Agent ID and Agent 365 give IT a way to discover, govern, and audit agents throughout their lifecycle, reflecting growing enterprise concern about agent sprawl and security exposure from agents that access data/tools and run code autonomously.
- "Agentic modernization" (Azure Catalyst) and "agentic operations" (Azure SRE Agent, Azure Copilot deployment agent, Azure Monitor health models) extend agents into legacy code modernization, vulnerability remediation, and cloud operations/reliability management, with claims of keeping "people in control."
- Infrastructure layer updates (Azure Cobalt 200 CPUs, pairing of Microsoft's own Maia/Cobalt silicon with NVIDIA/AMD, AKS for workload portability including to non-Azure servers) signal a strategy of offering customer-controlled, portable AI infrastructure rather than only fully managed services.
