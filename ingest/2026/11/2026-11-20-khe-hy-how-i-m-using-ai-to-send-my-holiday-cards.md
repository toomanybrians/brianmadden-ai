# How I’m using AI to send my holiday cards

## Insights

- Describes a multi-step personal workflow using an AI "agent" (a custom ChatGPT persona named "Seb") to automate a tedious data-aggregation task, showing how agentic AI tools are being applied to everyday personal admin, not just work tasks.
- The workflow relies on "computer use" capability to directly operate the user's machine, with model choice driven by which AI has the most reliable computer-use feature (noted as strong in this tool, weak in a competitor).
- Data is pulled from fragmented sources (old spreadsheets, emails, iMessages) via a mix of MCP integrations and a dedicated desktop plug-in that reads iMessages directly from the device.
- The author explicitly manages security risk around giving an AI agent access to personal messages by restricting it to read-only mode and requiring permission prompts for each search.
- The process treats a structured app (Notion) as a "source of truth" that the AI agent updates and later exports from, using a single natural-language prompt to transform database entries into a formatted CSV for an external service.
- Output still requires human spot-checking, with the AI flagging ambiguous or risky entries (e.g., two-line addresses, international addresses) via a notes column for manual review.
