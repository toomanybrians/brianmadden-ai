# Agents are going to work with enterprise files 100X more than people do today. T

## Insights

- Claim that AI agents will interact with enterprise files at roughly 100x the volume/frequency that human employees currently do.
- Box is partnering with Anthropic to provide full read/write interoperability between Box content and Claude, not just read-only access.
- This goes beyond simple content retrieval — agents can pull up content to work with directly inside a workflow.
- Anthropic separately announced "interactive connectors" letting users open full third-party tools (Adobe, Atlassian, Box) inside the Claude interface itself.
- Users can make changes themselves within these embedded tools, or direct Claude to make changes collaboratively.
- Feature is rolling out on Claude's web and desktop versions.

> Agents are going to work with enterprise files 100X more than people do today.
