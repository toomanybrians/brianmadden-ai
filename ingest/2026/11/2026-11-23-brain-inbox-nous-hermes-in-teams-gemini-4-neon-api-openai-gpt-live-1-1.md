# Nous Hermes in Teams 🤝, Gemini 4 Neon API 💡, OpenAI GPT-Live-1.1 🎙️

## Insights

- Nous Research released Hermes Enterprise, an AI agent that operates inside Microsoft Teams rather than requiring users to leave their workflow; users assign tasks (financial analysis, document drafts, inbox triage) in a chat thread and get results back in the same thread. It's MIT licensed/open-source, runs tasks in isolated Azure Container Apps sandboxes, and can deploy inside a company's own Azure tenant for data governance.
- A notable feature, "Collective Wisdom," lets Hermes save an individual employee's effective approach to a recurring task as a reusable "skill" that, after review, becomes available to the whole team — framed as automatic accumulation of organizational best practices.
- Google shipped Gemini 4 Neon, a mid-tier-priced model ($3/M input, $15/M output tokens) claiming top coding-agent benchmark results (beating Claude Opus 5.5 on one benchmark) and strong science-reasoning scores, with a 1M-token context window and four adjustable "thinking levels" to trade off cost vs. intelligence per task.
- OpenAI's GPT-Live-1.1 voice model ships to the API with a "standby mode" that pauses billing during silence (dropping cost from $0.05 to $0.02/minute), explicitly targeting the cost structure of always-on voice agents; also improves handling of accents and precise details like spelled-out letters/numbers.
- Separately flagged research: CMU/Stanford got a 27B model to rewrite its own weights without retraining to "grow smarter" — a potential break from the standard train-once-freeze-forever model paradigm if it scales.
- Other noted developments: a 37x-faster, 230x-lower-memory open-source local web scraper (Firecrawl); a 9B model reaching 56 effective layers via weight reuse; and a method compressing 1GB of Wikipedia to 105MB using only a neural network.
