# By predicting how the same DNA is read differently from cell to cell, AlphaGenom

## Insights

- AlphaGenome 2 is positioned as a model for predicting how identical DNA sequences are interpreted differently across different cell types.
- The tool is released for non-commercial research use, accessible via API and interactive Colab tutorials rather than as a general consumer product.
- A key capability highlighted is few-shot adaptation: the model can incorporate data from just a few dozen cells to model specific experimental conditions without retraining.
- Example use cases mentioned include modeling immune cell responses to vaccines and behavior of specific gut cells.
