# One of the first true innovations in security I've seen in a while. 

Basically

## Insights

- Cisco and OpenAI jointly built "Shirudo," an open-source Linux runtime that lets AI agents defend systems in real time without downtime.
- The system works by having agents write dynamic eBPF controls — kernel-level blocking of malicious code as it happens, rather than after-the-fact detection.
- Defensive patches are framed as "virtual patches" that can be managed in a package-manager-like interface, making agent-driven security actions more structured and operational.
- The stated purpose is to buy defenders more time to properly test and roll out permanent patches, rather than replacing the patching process entirely.
- The commentator frames this as a rare genuine innovation in the security field, implying most recent security developments have felt incremental by comparison.

## Quote

> Basically kernel-level malicious code-blocking in real time, and you can manage the virtual patches kind of like a package manager.
