# Profile storage shouldn’t add more work for IT.

Introducing Citrix DaaS Profile

## Insights

- Citrix DaaS Profiles Flex is a managed storage service (built with Microsoft Azure Files) that handles provisioning, sizing, encryption, and monitoring of user profile data for virtual desktops, removing that layer of infrastructure work from IT.
- The pitch frames current profile storage practice as manual guesswork: IT estimates capacity, configures permissions/encryption by hand, and assigns someone to watch for overflow — leading to either overprovisioning or running out of space.
- Three cited failure modes of DIY profile storage: admin hours sunk into building/monitoring it, employees losing paid work time rebuilding settings after desktop reassignment/replacement, and security gaps from unreviewed manual configuration that surface as audit findings.
- The service claims to standardize "profile management best practices" by default to reduce slow logons, inconsistent desktop experiences, and help-desk tickets tied to misconfigured profiles.
- Positions data location/residency as enforced by platform design rather than policy enforcement, framed as a way to meet regulatory requirements "by design."
- Recommends a measurement approach: baseline one employee group pre/post rollout, tracking cost (tickets, admin hours, storage utilization), value (rebuild time x hourly rate), and risk (storage incidents, out-of-policy data location, audit findings) at 30/90 days.

## Quote

> When it is slow, full or misconfigured, it costs employee time, IT effort, and data protection, and most companies measure none of the three.
