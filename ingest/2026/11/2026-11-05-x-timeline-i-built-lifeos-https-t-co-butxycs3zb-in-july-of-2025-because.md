# I built LifeOS (https://t.co/BUtXyCs3Zb) in July of 2025 because I wanted an AI

## Insights

- LifeOS is framed as an "AI harness" built on the premise that human enhancement, not just task execution, should be technology's goal — the stated problem is that AI is "brilliant at executing" but doesn't know what the user actually wants.
- It introduces "intent engineering" as a successor to prompt engineering: a system (TELOS) that interviews users once to capture mission, goals, beliefs, and challenges, then reasons against that context on every subsequent task.
- The core mechanic is a four-step loop applied uniformly to any task (code, writing, health, habits): Articulate (define done with checkable criteria), Climb (take the next step), Verify (require tool-based evidence, not "should work"), Learn (fold results back into the system).
- The system models work as closing a measurable "gap" between a defined current state and ideal state, advancing via verified steps rather than open-ended agent behavior.
- It's positioned as open-source (MIT license, installable via curl/GitHub) with a broader architecture of named subsystems (Cortex for memory, Atlas for asset graphing, Vigil for monitoring, Assay for evals, Ledger for versioning) suggesting an attempt at a full personal-AI operating system rather than a single tool.
- Success is explicitly measured against a subjective quality bar ("Euphoric Surprise" — aiming for a "9 or 10 / OMG this is brilliant" response) alongside the verifiable-evidence requirement.
