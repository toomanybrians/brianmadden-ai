# #CitrixWeek is over. Your next move starts now. 

Pick one application or workfl

## Insights

- Citrix frames the "adaptive enterprise" as an organization that absorbs change (AI adoption, security demands, cost pressure) without disrupting ongoing work or rebuilding existing systems.
- Introduces the concept of AI's "reach" — where AI touches data and systems via employee tool choices, embedded app features, and autonomous agents — and argues permissions need to scale with risk as agents move from reading to acting.
- Explicitly states agents should not automatically inherit the full access of the employee they act for; permissions should be scoped to the task, with defined approval checkpoints for actions.
- Announces SecurAccess capabilities (planned, timing not finalized) to detect when an agent is driving a browser and to control which tools agents can use.
- Expands SecurSpaces (previously developer-focused) to AI engineers and knowledge workers, offering a centrally-policy-controlled workspace for employees and agents to use approved company resources — includes a "Knowledge Worker Agent" for internal documents/apps.
- Promotes "Session Insights" as a visibility tool to observe actual workflow behavior before making changes, positioned as "visibility before transformation."

## Quote

> An agent working for an employee shouldn't automatically inherit everything that an employee can access.
