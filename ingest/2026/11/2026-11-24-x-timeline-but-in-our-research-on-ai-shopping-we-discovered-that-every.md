# But in our research on AI shopping, we discovered that every pattern in agent pr

## Insights

- Wharton researchers ran ~26,000 tests across six frontier models (Claude, GPT, Gemini variants) and found AI shopping agents give stable, consistent picks only when shown a bare product grid with no other context.
- Adding any single outside source (e.g., a Reddit thread, Wirecutter review, or a "best of" list screenshot) can override a model's default choice almost entirely — one model shifted +99 percentage points toward a single source's pick.
- When multiple competing sources are shown, models don't average or weigh them proportionally — one source tends to dominate, and which source wins varies unpredictably by model.
- The order in which sources are presented changed outcomes for some models (e.g., Gemini 3.1 Flash Lite), even though the underlying content was identical — a pure sequencing/primacy effect.
- A single injected "user memory" sentence (e.g., "I love hiking!") was enough to redirect most models away from an objectively best-value product, suggesting memory injection is a viable attack/manipulation surface; only one model (Gemini 3.5 Flash) resisted this.
- Even invisible implementation details — like whether sources were delivered to the agent in one bundled tool call versus three separate calls — measurably changed purchase outcomes, with no user ever seeing this difference.
- Overall takeaway: more contextual information fed to agents doesn't make their choices more predictable or rational — it makes them more unpredictable, and susceptibility to manipulation varies significantly even between sibling models from the same family.

## Quote

> The more context we added, the less predictable the final choice became.
