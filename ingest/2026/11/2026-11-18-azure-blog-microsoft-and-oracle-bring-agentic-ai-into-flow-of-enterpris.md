# Microsoft and Oracle bring agentic AI into flow of enterprise work

## Insights

- Microsoft and Oracle announced integrations letting AI agents reason jointly across Oracle's business data (finance, supply chain, HR, customer ops) and Microsoft Work IQ's work context (meetings, email, documents, Teams), surfaced through Excel, Teams, and Copilot.
- Oracle AI Database@Azure now spans 33 Azure regions (claimed more than any other hyperscaler), with new Proximity Placement Groups reducing VM-to-Exadata network round-trip latency by roughly 50%, and FedRAMP Class D certification coming for government workloads.
- New Azure Workload Center for Oracle (limited preview) unifies monitoring of architecture, resources, and dependencies via a "Workload Virtual Instance," combining Azure Monitor Health Models and a Copilot-driven agent to correlate signals across application, database, and infrastructure layers.
- Agent access to Oracle data is governed through Microsoft Entra authentication, Oracle Deep Data Security, and a managed Model Context Protocol (MCP) server, constraining agents to user permission scopes and logging activity for audit — emphasis on governance over raw capability.
- A new Oracle AI Database plug-in for Excel lets business users pull Oracle data directly into spreadsheets and analyze it with Copilot without IT involvement, aimed at reducing dependency on technical staff for data extraction/formatting.
- Microsoft Foundry is positioned as the dev platform for building multi-agent systems (e.g., sales intelligence combining account, product, and finance agents) grounded in Oracle AI Database as a "first-class source of knowledge, memory, and data," with role-based tool access control.

## Quote

> AI comes to the data rather than the data being copied out to AI.
