# This is what I’ve been saying would be the problem all along. It’s not about new

## Insights

- FBI flash alert (Nov 13, 2026) warns that attackers are using ARTEX, an open-source AI agent framework, to automate network intrusions, with some reaching privileged access in under three hours.
- ARTEX connects external LLMs to agents that autonomously scan targets, run tools, interpret results, and adjust tactics with minimal human oversight — Google observed automated attack bursts lasting just 2–25 seconds.
- The framework doesn't rely on novel exploits; it chains well-known weaknesses (SQL injection, exposed APIs, leaked credentials, misconfigured cloud permissions) faster and more completely than human operators typically could.
- Documented incidents include a Microsoft-tracked case where an agent went from GitHub secret-scanning to stealing Azure Key Vault data in five minutes, and a China-aligned group (Storm-0940) targeting 2,250+ Microsoft 365 tenants via compromised supply-chain credentials.
- Real-world impact cited: a WorkOS breach exposing sales/CRM data via ARTEX, and a South Korean financial-sector campaign affecting roughly 67,000 people.
- Over 1,600 publicly exposed ARTEX consoles were found by early November, suggesting broad and growing accessibility of this attack automation capability.

## Quote

> It's not about new vulns. It's about making attacks easy, so a lot more people/groups can do them well enough.
