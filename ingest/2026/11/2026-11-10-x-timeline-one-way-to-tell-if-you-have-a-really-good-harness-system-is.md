# One way to tell if you have a really good harness / system is if it takes longer

## Insights

- Proposes a diagnostic heuristic: the quality of one's "harness" or system (evals, workflows, standards) can be measured by how long it takes to notice improvements from new underlying models.
- Argues that if an evaluation/workflow system already enforces high standards, the marginal gains from a better model become harder to detect — the system effectively absorbs or masks model-level improvements.
- Implies an inverse relationship between system maturity and visible model-driven gains: weaker harnesses will show dramatic jumps when a new model arrives, while strong harnesses show subtler jumps.
- Frames "harness" and "system" as encompassing both evals and enforcement mechanisms, not just prompts or tooling.

## Quote

> One way to tell if you have a really good harness / system is if it takes longer for you to see the improvements from new models.
