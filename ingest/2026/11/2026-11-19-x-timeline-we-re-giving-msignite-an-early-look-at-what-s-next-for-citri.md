# We’re giving #MSIgnite an early look at what’s next for #CitrixDaaS on Azure. 👀

## Insights

- Citrix is doubling Azure subscription VDI limits to 10,000 VMs per subscription/region, aimed at reducing the number of subscriptions large enterprises must manage for identity, networking, and cost tracking.
- New "automatic recovery" feature will let virtual machines failover across Availability Zones, regions, or approved alternative VM sizes when Azure capacity is unavailable, reducing manual IT intervention during cloud disruptions.
- Citrix is extending Entra ID join capability beyond Azure to other hypervisors (starting with AWS and XenServer, with VMware/Nutanix/Hyper-V/Google Cloud planned), aiming to unify identity management across hybrid/multi-cloud estates without on-prem Active Directory.
- The "Citrix Intelligence Engine" is a new locally-hosted AI service designed to let Citrix HDX make data-handling decisions (starting with clipboard content classification/blocking) without sending sensitive data to external AI services — framed as a response to security leaders' reluctance to use third-party AI on sensitive data.
- Citrix DaaS Profiles Flex (built with Microsoft, powered by Azure Files) will offer fully managed, encrypted user profile storage to reduce IT's infrastructure burden for desktop personalization/continuity.
- New support for disconnected Azure Local deployments targets government, defense, and regulated/remote sites needing full VDI lifecycle management without any public cloud connectivity.

## Quote

> Almost every security leader I talk to wants to use AI to protect sensitive data. Almost none of them want to send that data to an outside AI service.
