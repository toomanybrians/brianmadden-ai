# We worked with teachers to help build this initial version. It is neutral as to

## Insights

- Primer is described as an agent-driven system: a teacher talks through a lesson and the system generates a playable simulation for students, grounded in pedagogy.
- The tool was built with direct input from teachers during its initial development.
- It's designed to be model/technology-neutral, meaning users can adapt it to different underlying AI systems rather than being locked into one.
- The released paper includes code and prompts, and a specific final appendix contains a prompt designed to let an AI agent read the paper and build its own version of Primer from it — framed as "a paper you can run."
- The release is positioned as open and intended for educators and researchers to build upon.
