# Where in the World Have We Been

## Insights

- The Open Memory Protocol Initiative (launched with Mozilla and IBM, 30+ companies involved) aims to let AI agent memory move between systems rather than stay locked in proprietary silos — current coding agents (Claude Code, Codex, goose, etc.) each store memory incompatibly, creating lock-in and blocking cross-agent collaboration.
- The protocol's ambition goes beyond portability to true shared/concurrent memory — multiple systems reading and writing to a common memory object simultaneously, demonstrated live across a Markdown store, knowledge graph, and search index, and even with a robot via MCP.
- A Microsoft Research roundtable identified "missing mechanisms" in the AI data economy: no good systems yet exist for attribution, pricing, licensing, collective bargaining, or rating the quality of training data — one proposed fix is independent data-rating agencies so better data can command higher prices.
- Analysis of Anthropic's IPO filing argues AI companies need standardized, oil-and-gas-style disclosure of token volumes, revenue/cost per token, and compute commitments (Anthropic has ~$895B in future compute commitments) — without this, efficiency claims and financial exposure are unverifiable.
- A membership-inference study (accepted to AI and Ethics) found evidence GPT-4o had been trained on paywalled O'Reilly books (text recognition pattern), while smaller GPT-4o Mini showed no such pattern — supporting calls for mandatory training-data disclosure and formal content licensing.
- Separate research finds that in the US, spending on data processing/cloud services rose from $0.55 to roughly $2 per $100 of industry input spending since 1997, with profits concentrating among a handful of cloud providers who own infrastructure while customers rent compute — raising questions about shifting economic rents and inequality.
- A parallel project (with O'Reilly Media and Miso.ai) is prototyping a marketplace to pay authors of AI agent "skills" (packaged task instructions), using a new benchmark suite (SkillProof, 30+ tests) to verify whether a given skill actually improves agent performance.
