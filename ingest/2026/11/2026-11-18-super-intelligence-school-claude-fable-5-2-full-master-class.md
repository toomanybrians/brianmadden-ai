# Claude Fable 5.2 Full Master Class

## Insights

- A single log can produce two legitimate but contradictory metrics (50% vs. 80% "success rate") depending on whether every attempt is counted or only each job's latest result — the data isn't wrong, the label is.
- The course frames a good LLM capability test as whether the model asks clarifying questions (what does each report actually count, what are the job IDs/attempt numbers/outcomes) rather than guessing which figure is "wrong" or jumping straight to writing code.
- Anthropic released two versions of the same underlying model simultaneously on November 9, 2026: Claude Mythos 5.2 (verified organizations only) and Claude Fable 5.2 (paid consumer users, with extra cybersecurity/biology safeguards) — access tier, not capability, is the distinguishing factor.
- The master class structure moves from ambiguous data interpretation (browser-based record/screenshot analysis) to applied building (Claude Code implementing a Python report) to operational judgment (reading API usage/cost figures to decide when a harder task justifies extra expense).
- Practice materials include sample data, a working Python report, and seven tests, suggesting the pedagogical emphasis is on verifiable, checkable outputs rather than taking the model's answer on faith.

## Quote

> The label "success rate" is what needs fixing.
