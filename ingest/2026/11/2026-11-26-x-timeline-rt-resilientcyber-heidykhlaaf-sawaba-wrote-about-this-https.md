# RT @ResilientCyber: @HeidyKhlaaf @sawaba wrote about this https://t.co/Z9yXEBGT9

## Insights

- Anthropic's Mythos (AI vulnerability-discovery tool) is characterized as functioning like a lead funnel: it finds bugs at scale, then the same AI vendors sell expensive inference to fix them, creating a self-reinforcing revenue loop.
- Independent researchers (AISLE, Vidoc) reportedly found cheaper models could match Mythos's vulnerability discovery, suggesting the real differentiator isn't model power/cost but security expertise needed to build harnesses and validate results.
- Argues this dynamic raises the "security poverty line" — only well-funded engineering orgs can afford AI-driven vuln discovery/remediation, leaving smaller organizations more exposed.
- Claims the vast majority of CVEs (98%+) have no real attacker value, so mass AI-driven vulnerability discovery risks generating noise/cash burn rather than actual security improvement, while branding routine findings as "zero days."
- Raises concern that AI-generated code fixes are being applied faster than they can be reviewed, creating unknown risks to codebase stability/security, and speculates this may be linked to recent major outages attributed to "vibecoding."
- Notes a chilling effect on open source as repositories go private to cope with increased vulnerability disclosure pressure ("vulnpocalypse").
