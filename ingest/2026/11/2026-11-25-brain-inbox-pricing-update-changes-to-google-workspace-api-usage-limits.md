# [Pricing Update] Changes to Google Workspace API usage limits starting Feb 2027 and new AI policies

## Insights

- Google is restructuring Workspace API access into two tiers (Standard: free with rate limits; Scaled: paid above free allowance), with Gmail, Drive, and Calendar first, effective pricing changes starting April 2027.
- Starting February 1, 2027, Google will technically enforce a requirement that AI agents and similar automated tools must access Workspace data via MCP (Model Context Protocol) servers rather than calling REST APIs directly — a structural shift in how agentic tools are permitted to integrate with Workspace.
- Google frames this change explicitly as a response to "unprecedented growth" in AI agent usage driving both demand on Workspace services and new data security/privacy risks.
- A new "Workspace AI Tools Addendum" introduces explicit prohibitions on AI agents storing certain API-derived data for extended periods or using agents to scrape Workspace APIs, alongside a liability disclaimer for harms from third-party AI tools accessing Workspace.
- Any request for increased usage quotas will now require enrollment in the paid Scaled tier, effectively monetizing higher-volume agentic/automated access.
- Google Cloud Support customers get a temporary exclusion of Workspace API usage from support fee calculations, but only guaranteed until December 2027.

## Quote

> AI agents have experienced unprecedented growth, generating rapidly growing demand for Workspace services and increasing data risks.
