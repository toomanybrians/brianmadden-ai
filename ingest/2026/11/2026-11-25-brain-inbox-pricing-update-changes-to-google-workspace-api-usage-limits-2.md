# [Pricing Update] Changes to Google Workspace API usage limits starting Feb 2027 and new AI policies

## Insights

- Google is formalizing a requirement that AI agents and similar tools must access Workspace data (Gmail, Drive, Calendar) via Model Context Protocol (MCP) rather than direct REST API calls, with technical enforcement starting February 1, 2027.
- The move is framed as a response to "unprecedented growth" in AI agent usage driving demand on Workspace services and raising data-access security/privacy risks.
- A new two-tier usage model (Standard: free with rate limits; Scaled: paid above free allowances starting April 1, 2027) effectively monetizes higher-volume agentic/API access to enterprise productivity data.
- New "Workspace AI Tools Addendum" terms explicitly prohibit certain AI agent behaviors — e.g., extended storage of data derived from API use and scraping Workspace APIs — and disclaim Google's liability for harms from third-party AI agents accessing Workspace data.
- This signals infrastructure-level governance being imposed on the AI-agent ecosystem by a major enterprise software provider, shifting agentic access to enterprise data (email, files, calendars) into a controlled, metered, and policy-bound channel rather than open API access.
- Quota-increase requests will now require enrollment in the paid Scaled tier, pushing any organization running higher-volume AI agents toward direct cost exposure.
