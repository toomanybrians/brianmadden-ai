# With Lilach Mollick Ben Przystanski, LJ Ciccarelli, Natalie Bach, and Laura Zarr

## Insights

- Primer is an experimental open-source platform (Wharton Generative AI Labs) for building interactive, multi-modal AI experiences combining realtime voice, visuals, and autonomous agent decision-making — positioned as more like an "AI-driven game" than a chatbot.
- Explicit design philosophy: general-purpose AI models aren't built for learning out-of-the-box, so the team built a layer that puts control back in educators' hands to shape experiences for pedagogical use.
- Each "experience" is defined by a config file specifying agent personalities/voices/instructions, visual/sound scenes, flow logic between agents, and available tools (notes, image generation, web search).
- Architecture is modular: self-contained "modules" (templates, tools, agents) are installed from a registry, with dependency resolution (e.g., an Experience Creator module auto-installs Roleplay and Teachback templates it depends on).
- Built on OpenAI's Realtime API (requires funded account with GPT-4 access) with optional Anthropic/Claude support; extensibility documented for LMS integration (LTI 1.3), database swaps, auth/SSO changes, and adding new model providers.
- Project was built via human-AI pair programming, with Claude involved in architectural and refactoring decisions — an explicit acknowledgment of AI-assisted development process.

## Quote

> We wanted to make sure we gave control to educators so they can make choices.
