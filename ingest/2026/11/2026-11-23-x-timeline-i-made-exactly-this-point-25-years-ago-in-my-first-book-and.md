# I made EXACTLY this point 25 years ago in my first book, and still barely anyone

## Insights

- The universal approximation theorem guarantees that a neural network with at least one hidden layer and enough nonlinear activation nodes can represent (approximate) any function.
- This theorem says nothing about whether such a network can actually *learn* that function from a finite set of input-output training pairs — representational capacity and learnability are distinct properties.
- The point is framed as long-standing and under-appreciated: one commenter traces it back 25 years to an early book, suggesting it's a persistent, often-overlooked limitation in how people reason about neural network capabilities.

## Quote

> any neural network... can approximate any function but it doesn't say that that NN can learn any function given input-output pairs
