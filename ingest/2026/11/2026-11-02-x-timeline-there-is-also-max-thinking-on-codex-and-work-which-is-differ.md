# There is also Max Thinking on Codex and Work, which is different than Pro Mode,

## Insights

- Codex and Work (ChatGPT's work-oriented interface) has a "Max Thinking" mode distinct from "Pro Mode," and it sometimes must be manually enabled via a menu setting rather than being on by default.
- Max Thinking is described as the highest reasoning mode available within Codex and Work specifically, but it is not the same as or as capable as Pro mode.
- Pro mode is only accessible through the Chat interface, not through Codex and Work.
- What looks like the top-tier mode in Codex and Work is actually called "Ultra," and it behaves differently — it spawns multiple agents to work on a problem rather than doing single-threaded deep reasoning.
- Max Thinking is positioned as a middle tier: more capable reasoning than default, but not biased toward launching many agents (unlike Ultra) and still below Pro in overall quality.
- The naming and availability of these modes (Pro, Max Thinking, Ultra) across different ChatGPT interfaces is described as confusing, even to experienced users.

## Quote

> Confusingly, you can only access Pro mode in the Chat interface.
