# Claude Second Brain & Folder Workflow: The Full Guide

## Insights

- Anthropic tested Claude against roughly 350,000 files; on a benchmark set of questions, file search alone scored 53% accuracy.
- When Claude was also given a set of connected notes built from those files, accuracy rose to 61% — framed as an experiment, not a guaranteed result for all use cases.
- The piece frames this as evidence that maintaining organized, accumulated knowledge can matter as much as using a more capable model.
- Describes a recurring problem with Claude: without persistent notes, it resurfaces previously rejected ideas or forgotten decisions buried in old conversations.
- Proposes a lightweight "second brain" approach for Claude users — not a full database or app, just a small, returnable store of key context — covering what to save, how Claude can maintain it, and its use with Cowork, skills, and automations (detailed in the full paywalled guide).

## Quote

> Keeping useful knowledge is sometimes as valuable as getting a smarter model.
