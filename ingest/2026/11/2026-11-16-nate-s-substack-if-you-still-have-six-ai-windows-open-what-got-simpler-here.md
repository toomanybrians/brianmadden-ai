# If you still have six AI windows open, what got simpler? Here's what it looks like to ask one office manager what happened and what needs you.

## Insights

- Running multiple AI agents (email, scheduling, coding, etc.) creates a new coordination burden: each agent can surface its own "reasonable question" at the end of a work session, and the human ends up reconciling multiple parallel reports instead of saving time.
- The piece frames "personas" as reusable judgment: a persona encodes how a person makes tradeoffs/decisions so any agent can consult it, meaning the judgment only needs to be taught once but can inform many agents' work.
- Oddboro (an open-source desktop app, built by Josh Pierce) proposes a single "office manager" agent as a unifying interface — a layer that triages what happened across agents and surfaces only what needs human attention, rather than requiring separate check-ins per agent.
- The office manager asks clarifying questions up front (which account, what counts as "needing action") so it can route tasks to the right agent — pushing the human to define judgment criteria once rather than repeatedly.
- The app uses a literal "office" metaphor (folders on shelves = read access, folders on desks = edit access) to make agent permissions legible to non-technical users, with a goal of eventually supporting headless/terminal use for power users.
- Current features (as of the piece): agents can hand off work to each other, access permissioned folders, draft Gmail replies that wait for human send, with read-only as a default office rule; Gmail integration is still limited pending Google verification.
- The stated end goal is "calm" — not more automation per se, but reducing the number of distinct conversations/interruptions needed to stay coordinated across agents, so a human can resolve one real decision after a break and return to planned work.
