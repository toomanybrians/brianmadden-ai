# [Legal Update] Updates to Google Cloud Service Specific Terms

## Insights

- Google Cloud is adding a new "GCP Access Tools" section (Section 17) to its Service Specific Terms, effective January 1, 2027, specifically to govern how AI agents and automated tools interact with Google Cloud Services.
- The update targets access via APIs, Google's Model Context Protocol (MCP) servers, and "similar access points" — an explicit acknowledgment that AI agents are now a distinct access modality requiring its own legal framework, separate from traditional human/API usage.
- New prohibitions include using AI agents to scrape APIs or MCP servers, and storing product-related information obtained via these access points for "extended periods of time" — framed as security risk mitigation.
- Google is disclaiming liability for harms caused by third-party AI agents or tools accessing its Cloud Services through these channels, shifting risk exposure onto customers/developers using agentic tools.
- Non-compliance is framed as a breach of the underlying service agreement, making this a binding contractual change rather than guidance.
- The update signals that MCP and agentic access patterns have become common/significant enough at Google Cloud scale to warrant dedicated terms — an indirect data point on enterprise AI agent adoption.

## Quote

> We disclaim harms potentially caused by using third-party AI agents or other tools to access Google Cloud Services.
