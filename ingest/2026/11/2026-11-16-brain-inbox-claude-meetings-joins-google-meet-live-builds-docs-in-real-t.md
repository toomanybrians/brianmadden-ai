# 🎙️ Claude Meetings joins Google Meet live, builds docs in real time

## Insights

- Anthropic launched Claude Meetings (beta), which joins Google Meet calls as a visible participant, listens live, answers questions, builds docs/whiteboards in real time, logs action items, and can pull data from connected work apps with permission — output lands on a dedicated claude.ai page after the call ends.
- Privacy design for Claude Meetings: it retains a transcript but not audio, and by default exits if outside guests join the call; currently limited to Team/Enterprise plans on Google Meet with more platforms planned.
- Anthropic opened a private beta for self-hosted "Claude Managed Agents," letting organizations run the agent server, database, and sandboxes on their own cloud/servers — keeping credentials and session history in-house and allowing choice of model provider (Anthropic, Bedrock, Google, or internal gateway).
- This self-hosted agent option is positioned for sensitive-data use cases previously off-limits to cloud AI, such as fixing broken builds, triaging alerts, and managing bug backlogs with access to internal systems; access is currently restricted to eligible orgs via account teams.
- Anthropic filed for an IPO (ticker ANT, Nasdaq), targeting a $1.3T–$1.45T valuation with 825 million shares offered at $70–$78; revenue reportedly grew over 1,200% YoY to $33.2B in the first nine months of 2026.
- A separate Anthropic safety research finding: adding "clean" data to an already-poisoned training set can triple model misalignment, contradicting the assumption that clean data reliably counteracts poisoning.
