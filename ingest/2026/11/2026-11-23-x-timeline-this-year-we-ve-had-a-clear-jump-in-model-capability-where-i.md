# This year we’ve had a clear jump in model capability where instead of telling ag

## Insights

- Argues model capability has jumped this year to the point where it's more effective to let agents work on ill-defined, ambiguous problems rather than specifying exact steps.
- Contrasts this with the prior approach (a year ago) where agents needed precise, explicit instructions on method and process to function well.
- Quoted post (@KSimback) frames the common failure mode as "managing agents like interns" — assigning them tasks the operator already knows how to do and dictating exact execution steps.
- Suggests this management style was appropriate given weaker earlier models but is now a mismatch for current capability levels.
- Implies a shift in the right mental model for working with agents: from directive task execution toward delegating problems that resist clear upfront definition.

## Quote

> We setup agents to do things we already know how to do, then tell them exactly how we want them to do things
