# With @ArtificialAnlys, we built MKA (Multimodal Knowledge Agent): a benchmark fo

## Insights

- Google DeepMind, with Artificial Analysis, built a new benchmark called MKA (Multimodal Knowledge Agent) to measure how well AI agents handle visually complex professional tasks.
- The stated rationale: everyday professional work often requires more than text — e.g., cross-referencing blueprints, reading scientific charts — and existing benchmarks don't cover this.
- A related/referenced capability ("Carbon") is described as handling dense multimodal file synthesis, building interactive 3D web experiences, and uncovering software vulnerabilities, framed as requiring "sustained reasoning."
- This capability is rolling out in the Gemini App and AI Mode in Search, available to Google AI Ultra subscribers.

> Everyday professional work often uses more than just text – from cross-referencing blueprints to reading scientific charts.
