# Claude Duet: Anthropic Built a Powerful AI Agent for You

## Insights

- Anthropic released Claude Duet (Oct 21), an AI agent built on Claude Opus 5.5, positioned as distinct from a chatbot — it operates with its own computer, connects across apps, retains memory of ongoing work, and continues tasks autonomously while the user is away.
- The agent can proactively initiate contact with the user when it determines something needs attention, rather than waiting to be prompted.
- It integrates with over 6,000 connectors/plugins, extending its reach well beyond conversational interaction into actual task execution across a user's tool stack.
- Setup is framed around delegation: users give Claude a defined scope of responsibility via instructions, allowing it to "look after" part of their work without requiring approval for every decision.
- The example given (Claude noticing an unflagged scheduling conflict between a client call and a flight, then offering to resolve it) illustrates the agent surfacing problems the user hadn't consciously tracked.
