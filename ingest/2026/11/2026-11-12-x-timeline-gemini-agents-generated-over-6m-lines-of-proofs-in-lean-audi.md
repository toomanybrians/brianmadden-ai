# Gemini agents generated over 6M lines of proofs in Lean, auditing the code so hu

## Insights

- Google DeepMind reports Gemini agents generated over 6 million lines of formal proofs in the Lean proof assistant language, applied to verifying software infrastructure.
- The workflow reduced human review burden dramatically: agents audited the generated proof code so human experts reportedly only needed to check roughly 1% of it.
- The announcement frames this as a step toward using AI to formally verify "vital infrastructure" — examples cited include communication systems and power grids.
- A specific prior result referenced: using a framework called "AlphaProof Code," the team claims to have mathematically proven Signal's messaging protocol secure "down to the code level," verifying the cryptographic system protecting its messages.
- This positions AI-driven formal verification (not just code generation) as an emerging application area, distinct from typical AI coding-assistant use cases.
