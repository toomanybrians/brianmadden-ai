# ⚙️ ChatGPT is becoming Google's biggest threat

## Insights

- ChatGPT now handles roughly one-fifth the query volume of Google (which holds ~90% of global search share), putting ChatGPT's search-like usage at more than triple Bing's — a sign AI chat interfaces are becoming a genuine alternative to traditional search, not just a writing/coding tool.
- OpenAI is merging ChatGPT's "Chat" and "Work" tabs into a single interface that infers whether a user wants a quick answer or a longer agentic task, removing a friction point between conversational and task-based use.
- GitHub's Octoverse report shows agents started 40% of all pull requests in September 2026 (up from 17% six months earlier), with total code pushes exceeding the prior two years combined — alongside a 230% YoY jump in cloud-agent usage vs. 85% for agent chat, indicating a shift from AI-as-answerer to AI-as-task-delegate.
- GitHub's data suggests the software developer role is shifting toward deciding what to build, selecting models/tools, and judging agent-generated output — rather than being displaced, demand for developers is reportedly rising because there's more code to manage; this pattern is framed as a preview for other professions.
- Menlo Ventures data shows enterprise AI deployment spend hit $177B (5x YoY growth, outpacing model-development costs of $102.5B), with agents now accounting for 80% of tokens on OpenRouter — but the report notably measures deployment spend, not realized ROI, leaving the value question open.
- Within enterprise spend, Anthropic and OpenAI are gaining share (55% and 31% respectively) while Google's share fell to 9%, even as frontier labs collectively lost some ground to open-source models, which now handle 19% of tokens at only 4% of spend.

## Quote

> "We're moving to a world where agents will write the first draft of the code while professional developers will develop a process to review the outputs and manage quality and risk." — Tala Karadsheh, GitHub
