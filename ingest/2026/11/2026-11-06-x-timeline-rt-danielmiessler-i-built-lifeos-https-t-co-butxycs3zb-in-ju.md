# RT @DanielMiessler: I built LifeOS (https://t.co/BUtXyCs3Zb) in July of 2025 bec

## Insights

- LifeOS is pitched as an "AI harness" built on the premise that current AI is "brilliant at executing" but doesn't know what the user actually wants — the product's core problem statement is a gap between capability and intent.
- Central concept is "intent engineering" (vs. prompt engineering): a system called TELOS interviews the user once to capture mission, goals, beliefs, and challenges, then carries that context into every subsequent task.
- The product operationalizes work as a repeatable four-step loop — Articulate (define done with checkable criteria), Climb (take the next step), Verify (require tool-based evidence, not "should work"), Learn (feed results back into the system) — applied uniformly to code, writing, health, and habits.
- Verification is treated as non-negotiable: every completed step must close against proof from a tool, framed as "no evidence, no step."
- The system includes a large set of named subcomponents (Cortex for memory, Atlas for asset/access graphing, Vigil for always-on monitoring, Ledger for versioned change tracking, Assay for eval/judgment, etc.), suggesting an attempt at a full personal "operating system" architecture rather than a single-purpose tool.
- It's open-source (MIT license, installable via curl/GitHub) and designed to be installed into existing coding agents like Claude Code, Cursor, or Codex rather than functioning as a standalone app.

## Quote

> Your AI is brilliant at executing. It just doesn't know what you actually want.
