# Anthropic just turned Claude into an App Store that Apple can’t see 🍎🛍️; Amazon may unblock Meta’s AI Shopping Agent, and the fight is all about search & ads 🤖📈

## Insights

- Anthropic's new "Install as app" feature converts any Claude artifact into a standalone desktop app for Mac or Windows.
- These installed apps run inside Claude's own process, draw on the user's existing Claude subscription/plan, and request system permissions through Claude rather than through the OS app store review process.
- This effectively lets Anthropic operate a de facto personal app store that bypasses Apple's App Store review entirely.
- Apple's newest macOS permission controls are described as largely blind to this — they register only "Claude" as the app, not the individual artifact-apps running inside it.
- The piece frames this as raising a strategic question for SaaS founders/investors: which categories of software become a mere "prompt" inside Claude, versus which remain a backend service that Claude calls into.
