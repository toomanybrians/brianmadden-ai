# The Morning Download: Anthropic’s Claude Output Can Be Installed as Software

## Insights

- Anthropic now lets Claude "artifacts" (previously shareable outputs like charts or webpages) be installed as standalone desktop apps on Mac and Windows, in beta.
- Installed apps get their own icon and window, run outside the Claude environment, and require explicit user permission to interact with the computer — framed as a user-controlled permission structure.
- Anthropic describes internal examples: Linnet (an image editor) and Sift (a folder-organizing tool using Claude to maintain order), suggesting employees are building bespoke software tools rather than using off-the-shelf apps.
- Use cases cited include recurring work tools like a meeting-prep page pulling from calendar/email, or a daily shipping-order tracker — i.e., persistent, personalized micro-applications rather than one-off outputs.
- This caps a year of Anthropic moves toward Claude handling multistep work autonomously, including January's Cowork (assigning Claude tasks like file organizing, drafting, spreadsheet data extraction) and February's open-source plug-ins for customization (including legal-profession-focused ones).
