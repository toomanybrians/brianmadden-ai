# Your old Cowork tasks might not be missing?

## Insights

- In Claude's newly combined Chat and Cowork interface, search does not index older Cowork tasks, which can make prior work appear lost even though it isn't deleted.
- Anthropic's workaround: older tasks remain accessible by searching for them by name under "Recents" rather than via general search.
- For desktop Cowork users, past outputs and connected local files can be recovered via Settings → Storage folder and Trusted folders.
- Recommended end-of-session habit: prompt Claude to generate a project handoff note covering current goal, decisions made, files changed, unresolved problems, and next steps, with file-location verification before saving.
- The suggested handoff prompt includes a safeguard step requiring confirmation of save location and whether an existing file (e.g., STATUS.md) would be overwritten.
- The author frames this as a practice for avoiding the need to reconstruct work later, with a more complete "session-closeout workflow" reserved for a paid archive.

## Quote

> Create a project handoff note with the current goal, decisions made, files changed, unresolved problems, and the exact next step.
