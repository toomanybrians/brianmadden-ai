# 🤖 xAI Grok Bot logs into your tools autonomously, $120/seat

## Insights

- xAI released Grok Bot, an autonomous agent (not a chatbot/coding assistant) that gets its own cloud computer, logs into a user's actual browser-based tools/accounts with credentials, and continues working after the user closes their laptop — no API integration required.
- Grok Bot's pitch: any browser-accessible tool becomes automatable without custom integration work, with example use cases including CRM upkeep, customer support, overnight account research/outreach drafting, and vendor negotiation "in your own voice." Priced at $120/seat/month with no free tier, available across major desktop/mobile OSes.
- Same week, DeepSeek open-sourced "Harness v0.1," a plugin-first agent framework for building coding agents under MIT license (free, no commercial restrictions) — architected so every component (model, tools, memory, filesystem, UI) is a swappable plugin, with four preset modes and full session traceability via replayable/forkable logs.
- The newsletter frames these as two opposing strategic bets on "who wins the agentic layer": xAI's closed, expensive, ready-to-deploy autonomous worker vs. DeepSeek's open, free, build-it-yourself framework.
- Separately, a partner piece (Teleport) argues that Zero Trust security models are insufficient for AI agents acting autonomously at scale, proposing "Agentic Trust Principles" — continuous enforcement, bounding collective autonomy, and assuming misalignment rather than just breach.
- Other noted signals: OpenAI shipped a faster model tier (GPT-5.6 Sol, 750 tokens/sec via Cerebras hardware, no intelligence tradeoff) and a "Computer History" feature so ChatGPT retains memory of a user's work across apps; a small-model study claims scaling laws can be predicted from cheap, tiny training runs.
