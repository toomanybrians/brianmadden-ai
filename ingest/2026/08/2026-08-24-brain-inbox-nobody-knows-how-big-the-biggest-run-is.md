# Nobody Knows How Big the Biggest Run Is

## Insights

- Frontier AI labs have sharply reduced disclosure since May 2026: token counts, GPU-hours, cluster size, and training cost have largely disappeared from model cards and technical reports, even as report length and author counts grow (e.g., DeepSeek's V4 report has 319 authors but no cost table).
- The shift is measurable, not perceptual: a full-text search of Kimi K3's technical report found zero mentions of a total token count, despite the same report discussing tokens-per-parameter as a tuned hyperparameter.
- Token counts partially survived into 2026 (GLM-5, DeepSeek-V4, MiniMax M2 disclosed theirs), but resource-level disclosure (GPU-hours, cluster size, cost) has nearly vanished — only DeepSeek-V3, Ai2's Olmo 3, and Switzerland's Apertus published full resource totals across the 2024–2026 record, and two of those three are non-commercial-frontier institutions.
- Meta is cited as the clearest before/after case: Llama 3 (2024) disclosed cluster size, duration, failure statistics, and token count in detail, while Meta's 2026 model Muse Spark 1.2 has an empty compute field in the same public database.
- Simultaneous with the disclosure blackout, physical infrastructure scaled roughly tenfold: the largest observed AI data center grew from ~80,000 H100-equivalent GPUs (Aug 2024) to ~760,000 (May 2026).
- The piece frames this as producing a genuine unknown: outside observers (and by extension regulators) can no longer determine how large the biggest pretraining runs actually are, undercutting the basis for scaling charts, regulatory thresholds, and claims that "pretraining is dead."

## Quote

> DeepSeek did not retract V3's famous cost table. It simply declined to publish one for V4.
