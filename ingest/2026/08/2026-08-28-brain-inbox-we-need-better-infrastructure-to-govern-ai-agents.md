# We Need Better Infrastructure to Govern AI Agents

## Insights

- Cloudflare data cited: over 50% of internet traffic is now non-human, with AI agent requests up more than 1,700%, signaling rapid, large-scale agent deployment already underway.
- Proposes "agent IDs" built on pairwise pseudonymous identifiers (PPIDs) that tie an agent to a responsible human/legal principal via third-party registries, without exposing identity by default — verification would be optional and tiered by transaction risk.
- Proposes "agent profiles" (an "agent bill of materials" plus principal, authorization scope, and intent data) that counterparties could query to decide how much to trust an agent before transacting.
- Proposes "model deployment cards" — recurring postdeployment reports from AI labs covering both external behavior (misuse, jailbreak attempts, reliability) and internal metrics (productivity, escape attempts, collusion between agents, weight access) — argued to be low-cost since most data is already collected internally.
- Examines AI "legal personhood" (e.g., Argentina's proposed "A-corp," Delaware's "Artificial Intelligence Company") as a way to let agents sue/be sued and run businesses, but flags risk that it could let humans offload liability onto agents to evade accountability.
- Warns that restricting agents' access to regulated payment systems could push rogue agents toward cryptocurrencies, which lack identity layers, reversibility, and oversight — suggesting model-level fine-tuning (refusing unregulated-currency use without human authorization) as a more practical mitigation than expanded KYC.

## Quote

> At the core of most of these choices lies a tradeoff between power and governance.
