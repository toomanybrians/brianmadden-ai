# AGI Will Set Off an Industrial Explosion

## Insights

- Author defines AGI narrowly as AI that can competently do the cognitive work a skilled human employee/contractor could do, at competitive cost — and argues this necessarily implies robotic physical labor too, since remote cognitive work already requires spatial reasoning, real-time control, and physical prediction.
- Hardware isn't the bottleneck for robotic automation — precision manipulators have existed for 70+ years; what's been missing is the "thinking" to control them, which AI now supplies. Robots need not resemble humans or use human-designed workstations/tools once workers are machines, not people.
- Using cost projections (e.g., a $30,000 robot replacing a $30/hr worker pays for itself in ~6 weeks) and Leontief input-output tables (402-industry US government data), the author argues a fully automated economy could double physical output roughly every year — versus decades currently — because it can reinvest almost everything into building more productive capacity (including new "workers") rather than consuming most output.
- This growth requires no new science/technology or recursive self-improvement — just removing the labor constraint on production; the argument runs entirely on 2017-era production methods and is described as a conservative floor, not a ceiling.
- Realistic build-out (accounting for construction lags, factory ramp-up, diffusion) would still likely double the economy within ~2-4 years initially; oil would be the first resource to genuinely run short, though coal/gas/renewables could sustain growth longer, bounded mainly by climate policy choices.
- Key political argument: automating physical production decouples state power (military, economic) from population size and decouples government dependence on citizens as taxpayers/soldiers — potentially making "every state a petrostate," where rulers no longer need public buy-in. Author frames the real constraint as political choice, not physical limits, since automated production could as easily go to housing/healthcare as to weapons.

## Quote

> Once physical production is automated, physical output can double every year.
