# Vibe Coding 2.0

## Insights

- "Vibe coding" is shifting from casual prompt-and-see improvisation toward a structured discipline: Google's AI Professional Certificate now teaches planning, testing, debugging, and deployment alongside prompting, not just "prompt an app."
- Google reports US search interest in "vibe coding" up 140% year-over-year, signaling rapid mainstream adoption of the term/practice.
- The piece argues the more durable workflow is: idea → simple plan → small tasks → AI builds → AI tests → human checks → continue — replacing the old pattern of one giant prompt producing thousands of lines of code to hope works.
- Frames the key shift as being less about model capability and more about the surrounding scaffolding: plans, small persistent memory, reusable "Skills," tool access, tests, and defined stopping rules.
- Notes concurrent model upgrades cited as context: OpenAI's GPT-5.6 Codex family (Sol, Terra, Luna tiers), Anthropic's Claude Opus 5 / Sonnet 5, and Google AI Studio's ability to go from natural-language request to full-stack web or native Android apps.
- References a "full guide" (paywalled/linked) covering SPEC.md, GitHub Spec Kit, project memory, agent loops, MCP/APIs, cost controls, and security checks as components of the more rigorous 2026 vibe-coding approach.

## Quote

> Not: idea → giant prompt → 4,000 lines of code → hope
