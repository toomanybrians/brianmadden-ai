# Anthropic’s Official Claude Code Masterclass + The Complete Learning Roadmap

## Insights

- Boris Cherny (Claude Code's creator) frames a shift in human-AI collaboration: away from single prompt-response cycles, toward building "routines" — configured workflows that handle prompting on the user's behalf.
- In this model the human's role moves from prompting directly to designing a job: providing the right context, tools, and self-verification steps, then letting the routine run.
- Demonstrated capability: Claude can execute multi-step, self-correcting work autonomously — writing code, testing it, detecting failures, fixing them, and re-testing, without step-by-step human direction.
- Routines can also operate on ongoing/background tasks — monitoring a pull request, repairing failed tests, responding to review comments — continuing work while the developer is occupied elsewhere.
- The piece treats this as a maturity curve for AI coding tools: from ad hoc prompting → structured working methods (CLAUDE.md, parallel agents, verification loops) → full systemized setups (subagents, MCPs, plugins, graph workflows) → model-level fluency (choosing between models, effort levels, and combining tools/agents/verification into one system).
- Underlying reframe: Claude Code is positioned not as "an AI that writes code" but as a system that can be taught to work, check its own output, fix errors, and keep going.

## Quote

> I'm not the one doing the prompting. I'm the one creating a routine that does the prompting. — Boris Cherny
