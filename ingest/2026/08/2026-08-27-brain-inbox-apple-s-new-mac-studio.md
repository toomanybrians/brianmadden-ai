# Apple’s New Mac Studio

## Insights

- Apple's new Mac Studio (M5 Max/M5 Ultra) offers up to 512GB unified memory and 1.2TB/s bandwidth, enabling large AI models to run locally without heavy reliance on cloud GPUs.
- Memory, not compute speed, is described as the binding constraint in AI infrastructure: Micron notes HBM consumes roughly 3x the wafer area of DDR5 for equivalent capacity, and that overhead isn't shrinking.
- Diverting wafer capacity to HBM production is squeezing commodity DRAM supply — contract DRAM prices rose 90-95% in a single quarter, pushing Amazon to raise device prices up to 60% on Echo, Kindle, and Fire TV.
- Nvidia is paying ~$6B for a non-exclusive license to Poolside's coding technology (plus ~$1B invested at a $12B pre-money valuation), absorbing about 109 Poolside engineers into its Nemotron open-weight model effort while Poolside remains independent — framed as Nvidia buying into the model layer beyond chips.
- Anthropic is reportedly preparing an IPO that could rival SpaceX's record debut, at a valuation near $2T, with run-rate revenue surpassing $65B in July against a 2025 net loss of about $42B.
- A GitHub outage was traced to a capacity shortfall that triggered Copilot's retry loop, spiking token traffic from ~8,000 to 100,000 requests per second — illustrating how AI-tool retry behavior can amplify infrastructure failures.

## Quote

> Speed is not the bottleneck anywhere in AI right now. Braking, power and memory are.
