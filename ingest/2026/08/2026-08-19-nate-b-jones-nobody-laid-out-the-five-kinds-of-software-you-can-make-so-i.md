# Nobody Laid Out The Five Kinds Of Software You Can Make. So I Did.

## Insights

- Frames non-developer app-building around "five software shapes" that determine nearly every subsequent build decision (tool choice, architecture, etc.), though the specific five aren't enumerated in the description itself.
- Argues the real bottleneck in AI-assisted coding isn't code generation but the human decisions the code depends on — what to build, where data lives, whether it actually works.
- Positions data location as a high-stakes early choice (e.g., Lovable Cloud vs. Supabase) because migrating data later is difficult.
- Covers concrete tool comparison across Lovable, Replit, Bolt, Codex, and Claude Code as the current landscape for personal software builders.
- Includes practical/technical scope beyond typical no-code talk: physical-world integration (sensors, Raspberry Pi), and real authentication/authorization/access control — not just UI generation.
- Emphasizes validating software against everyday use scenarios before anyone relies on it, treating testing as a core non-outsourceable step.
