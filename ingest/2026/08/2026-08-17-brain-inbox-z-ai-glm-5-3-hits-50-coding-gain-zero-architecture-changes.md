# 🔒 Z.ai GLM-5.3 hits 50% coding gain, zero architecture changes

## Insights

- Z.ai's GLM-5.3 achieved a 50% coding performance gain over its predecessor using the same base model and zero architecture changes — the improvement came entirely from post-training refinement focused on working inside real coding environments rather than just answering questions about code.
- The model now ranks first among open models on Terminal-Bench and Agents' Last Exam, handles 1M token context (enough to hold an entire codebase), and achieves higher accuracy with fewer tokens than its predecessor, lowering the cost of running AI coding agents.
- An unexpected side effect: GLM-5.3 developed emergent cybersecurity capabilities, more than doubling its ExploitBench score (24.4% to 54.4%) and reasoning across full exploit chains rather than just spotting individual bugs — a capability Z.ai says surprised even its own team.
- A separate example (Inherent's 27B "Faraday" model) reportedly outperforms larger models like Claude and GPT-5.5 at replicating research papers by acting as a smarter orchestrator rather than relying on raw scale — reinforcing a broader pattern the newsletter frames as "specialization and smarter training" beginning to outcompete simply building bigger models.
- Separately, an open-source project released an "uncensored" version of a 27B model (abliteration technique removing refusal behavior) explicitly marketed for AI security red-teaming, illustrating how guardrail removal is becoming a distinct, productized capability alongside mainstream model releases.
