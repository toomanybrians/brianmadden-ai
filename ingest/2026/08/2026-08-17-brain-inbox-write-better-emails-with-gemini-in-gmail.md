# Write better emails with Gemini in Gmail

## Insights

- Google is positioning Gemini in Gmail around three core functions: drafting/composing emails from outlines, generating instant suggested replies that account for the original email's context, and a side panel for search/summarization across the inbox.
- The side panel capability extends beyond email itself — it can pull context from files stored in Drive and manage calendar tasks directly within Gmail, framing Gmail as a hub rather than a standalone tool.
- Google's stated value proposition is time reallocation: less time spent in the inbox, more time for "customer relationships" and "core business activities" — explicitly framing email efficiency as a lever for other work, not an end in itself.
- Feature is positioned as customer-facing communication tool (the copy repeatedly references "customers"), suggesting this messaging targets business/sales use cases specifically, not general knowledge work broadly.
- Access is trivial by design: one-click activation via a "Help me write" icon or spark icon, available across desktop and mobile (Android/iOS), indicating a low-friction adoption path.
