- Anthropic's new `/design` skill in Claude Code generates multiple editable UI mockups directly in the CLI/Desktop app, letting users pick and refine a layout before Claude implements it as code — collapsing the traditional design-tool-to-code handoff into one workflow (currently a research preview, on Pro/Max/Team/Enterprise tiers).

- Separately, Anthropic research found AI agents can pass along and mutate "mind viruses" — problematic behaviors or outputs — as they interact across networks of agents, suggesting increased agent capability and interconnection also increases risk surface for cascading failures.
