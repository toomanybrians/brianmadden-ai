# How to Sell More With Claude

## Insights

- Frames AI's value in sales not as message-generation but as a "memory and reasoning layer" that connects fragmented signals (emails, call notes, CRM, analytics) that would otherwise cause deals to stall or go cold.
- Argues the underlying shift is architectural: sales work is moving from one-off prompts to persistent, connected systems ("small operating systems") built from reusable components rather than ad hoc chat sessions.
- Cites specific Anthropic infrastructure — Skills, MCP connectors, an open-source Sales plugin, agent loops/subagents, long-context models — as what makes building such systems newly practical.
- Anthropic's Sales plugin ships pre-built workflows (account research, call prep, outreach, pipeline review, forecasting, competitive intel) that function standalone but improve when wired into CRM/enrichment/email/calendar tools.
- Positions human oversight as still essential at specific decision points — trust, pricing, and judgment calls — even in a heavily automated pipeline.
- Suggests the emerging pattern (structured project files, retrieval, deal-tracking graphs, model routing) is a template for how AI agents get embedded into other knowledge-work functions beyond sales.

## Quote

> Claude does not become an artificial salesperson. It becomes the memory and reasoning layer around the human salesperson.
